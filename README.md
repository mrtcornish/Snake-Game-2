Snake Game (Phase 2)

This project is a browser-based Snake Game developed as part of my Web Technologies coursework.

Live Demo

https://mrtcornish.github.io/Snake-Game-2/

Features

* Classic snake movement and growth
* Score tracking
* Game over detection
* Interactive UI with multiple pages (Home, Play, About)

Technologies Used

* HTML
* CSS
* JavaScript

Project Structure

* index.html (Home page)
* play.html (Game page)
* about.html (About page)
* style.css (Styling)
* script.js (Game logic)

 Notes

This is Phase 2 of the project, with improvements in UI, gameplay, and structure compared to Phase 1.
